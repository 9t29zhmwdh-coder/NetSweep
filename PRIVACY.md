# Privacy Policy

NetSweep is a local Windows desktop application for scanning and cleaning network drives.
All file system data, scan results, and quarantine logs remain exclusively on your machine.

- **No telemetry:** The application does not collect or transmit usage data.
- **No cloud sync:** All operations are local : your NAS/UNC paths are never shared externally.
- **Quarantine:** Quarantined files are moved to a local folder of your choice, never uploaded.

Network traffic is generated only to the UNC paths you configure within your own network.
